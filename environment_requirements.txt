Recommended environment for TeF-SAM

Python:
  python >= 3.10

GPU / CUDA:
  NVIDIA GPU with CUDA support is recommended.
  CUDA 11.8 or newer is recommended for PyTorch GPU training/inference.

Core packages:
  torch >= 2.0
  torchvision
  transformers >= 4.30
  einops
  numpy
  pillow
  tqdm
  segment-anything

Optional packages for training or evaluation:
  monai
  torchmetrics
  scikit-learn
  opencv-python

External model checkpoints:
  SAM or MedSAM checkpoint, for example medsam_vit_b.pth.
  A local or downloadable vision encoder checkpoint compatible with Hugging Face Transformers.
  A local or downloadable BiomedCLIP-compatible image-text encoder.

Install minimal dependencies:
  pip install -r requirements-minimal.txt
